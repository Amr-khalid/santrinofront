## 🌟 نظرة عامة (Executive Overview)

**سنترينو أرينا** هو نظام حجز وإدارة متطور صُمم خصيصاً لملاعب كرة القدم والمجمعات الرياضية. يهدف النظام إلى تحويل تجربة حجز الملاعب التقليدية (المبنية على المكالمات الهاتفية والدفاتر اليدوية) إلى تجربة رقمية فائقة السرعة والسلاسة، تعتمد على الحجز الفوري اللحظي والتسعير الديناميكي.

تم بناء واجهة المستخدم بنمط **ملكي فاخر (Royal Emerald & Cream Palette)** يعتمد على الوضوح التام، البساطة، وخلو الواجهة تماماً من أي عناصر تشتيت أو حشو تسويقي.

## ✨ المميزات الرئيسية (Core Features)

### 1. جدول المواعيد المباشر والحجز المتعدد (Live Multi-Slot Booking)
* **عرض لحظي للساعات المتاحة** على مدار ساعات التشغيل (من 02:00 م حتى 02:00 ص).
* **حجز ساعات متعددة ومتتالية**: إمكانية حجز ساعتين أو ثلاث ساعات متصلة (مثلاً: من 02:00 م إلى 04:00 م) وقفلها معاً في قاعدة البيانات لمنع أي تعارض.
* **محدد المدة الذكي (Duration Selector)**: اختيار سريع للمدة المطلوبة (`1 ساعة` · `ساعتان` · `3 ساعات`) لتحديد الفترات بنقرة واحدة.

### 2. منتقي التاريخ المزدوج (Dual-Mode Date Picker)
* **الشريط السريع (Quick Strip)**: شريط أفقي سريع لعرض الـ 14 يوماً القادمة، مع إبراز رقم اليوم واسمه والشهر.
* **التقويم الشهري التفاعلي (Interactive Month Calendar Grid)**: تقويم شهري كامل للتنقل بين شهور السنة واستعراض التواريخ وتعطيل الأيام المنقضية تلقائياً.
* **أزرار الوصول السريع**: أزرار ذكية لـ (`اليوم` · `غداً` · `الويك إند`).

### 3. محرك التسعير الديناميكي (Dynamic Pricing Engine)
* احتساب الأسعار تلقائياً بناءً على فترات اليوم (ساعات الذروة، الساعات الصباحية، عطلات نهاية الأسبوع).
* توضيح سعر كل ساعة بوضوح بدون أي رسوم خفية.

### 4. تأكيد فوري وإصدار التذاكر (Instant Ticket Generation)
* نموذج حجز مبسط يطلب فقط الاسم ورقم الهاتف مع التحقق من صحة الرقم المصري.
* إصدار تذكرة حجز رقمية رسمية تحتوي على كود الحجز، تفاصيل الموعد، المبلغ الإجمالي، والموقع الجغرافي.
* لا يتطلب دفعاً إلكترونياً مسبقاً (الدفع نقداً في الملعب).

### 5. لوحة تحكم الإدارة وصاحب الملعب (Owner Dashboard)
* **إحصائيات الإيرادات والحجوزات**: إجمالي الدخل، نسبة الإشغال، وحجوزات اليوم والشهر.
* **جدول إدارة الحجوزات**: تصفية وبحث لحظي في الحجوزات وتأكيدها أو إلغائها.
* **إدارة قواعد الأسعار**: تخصيص أسعار ساعات الذروة والويك إند بسهولة.

## 🎨 نظام التصميم (Design System)

تم بناء الواجهة وفق هوية بصرية مخصصة تعكس الوقار والفخامة والاحترافية:

| العنصر | اللون | الكود | الاستخدام |
|:---|:---|:---|:---|
| **الرئيسي (Primary)** | أخضر زمردي ملكي | `#0D6B4F` | الأزرار الرئيسية، المواعيد المحددة، التمييز |
| **الثانوي (Accent)** | ذهبي ملكي دافئ | `#B8860B` | أرقام التذاكر، قواعد الأسعار المميزة |
| **الخلفية (Background)** | أبيض ناصع وموحد | `#FFFFFF` | خلفية الصفحة والبطاقات لتوحيد الرؤية |
| **الأسطح المرتفعة** | بيج دافئ خفيف | `#F8F6F2` | التقويم، مربعات الملخص، والتنبيهات |
| **الحدود (Borders)** | بيج رمادي ناعم | `#E8E4DC` | فواصل البطاقات والجداول بدون تباين مزعج |
| **النصوص (Typography)** | أسود فحمي داكن | `#1A1A1A` | العناوين والنصوص لأعلى درجات المقروئية |

### 🖋️ الخطوط المستخدمة:
* **`IBM Plex Sans Arabic`**: الخط العربي الرسمي لجميع النصوص والعناوين.
* **`Inter`**: للأرقام، الأسعار، الساعات، وتواريخ التقويم.

## 🏗️ التقنيات المستخدمة (Tech Stack)

* **إطار العمل (Framework)**: [Next.js 14](https://nextjs.org/) (App Router & React Server/Client Components).
* **لغة البرمجة (Language)**: JavaScript (ES6+).
* **التنسيق والأنماط (Styling)**: Vanilla CSS Modules & CSS Custom Variables.
* **الأيقونات (Icons)**: [Lucide React](https://lucide.dev/) (أيقونات وظيفية فقط بدون زحمة).
* **إدارة الحالة (State Management)**: React Context API (`AuthContext`, `ToastContext`).
* **التكامل مع السيرفر (Backend API)**: RESTful API مع معالجة الاستجابات السريعة و Fallback Resiliency.

│   │   ├── booking/            # مكونات الحجز (DatePicker, TimeSlotGrid, Modals)
│   │   ├── dashboard/          # مكونات لوحة التحكم والجداول والرسوم
│   │   ├── layout/             # الهيدر (Navbar) والفوتر (Footer)
│   │   └── ui/                 # عناصر UI الأساسية (Button, Input, Card, Modal)
│   ├── context/                # سياقات الحالة العامة (AuthContext, ToastContext)

## 🚀 التثبيت والتشغيل محلياً (Getting Started)

### المتطلبات الأساسية:
* **Node.js** (الإصدار 18.17 أو أحدث)
* **npm** أو **yarn**

### خطوات التثبيت:

1. **استنساخ المستودع (Clone the repository)**:
   ```bash
   git clone https://github.com/Amr-khalid/santrinofront.git
   cd santrinofront
   ```

2. **تثبيت الحزم والتبعيات (Install dependencies)**:
   ```bash
   npm install
   ```

3. **تشغيل بيئة التطوير (Run development server)**:
   ```bash
   npm run dev
   ```

4. **افتح المتصفح على الرابط**:
   ```text
   http://localhost:3000
   ```

## 📱 التوافق والأجهزة (Responsive Design)

تم تصميم وتطوير المنصة بمبدأ **Mobile-First**:
* متوافق 100% مع الهواتف الذكية بجميع أحجام الشاشات.
* شريط عائم سفلي على الموبايل لتأكيد الحجز فور تحديد الساعات.

* دعم اتجاه الكتابة من اليمين إلى اليسار (RTL Native Support).
